# 命名与归档规则

1. 一级目录使用“两位序号 + 技术主题”：`01_python_basics`、`02_fastapi`、`03_langchain`、`04_langgraph`。后续主题继续使用 05、06；90 用于参考课程。
2. 章节使用“两位序号 + 知识点”，不再用只有日期含义的 `1101`、`1102` 或 `day02` 作为主要入口。复习进度、学习日期记录在 README 中。
3. 新的 Python 模块使用小写英文和下划线，如 `weather_tool.py`。版本号写作 `v0_3`、`v1_0`，不在模块名中加额外小数点。
4. 已有中文基础课练习保留中文知识点便于复习，文件序号统一为 `01_知识点.py`。它们是直接运行的学习脚本；需要被 import 的模块使用合法模块名，不添加数字序号。
5. 保留 Python 和工具约定名称：`__init__.py`、`main.py`、`models.py`、`schemas.py`、`requirements.txt`、`README.md`、`.env.example`。不为统一外观强行重命名。
6. 课程原始资料放入 `90_course_materials`，内部课次、章节、包和素材名称保留，方便逐项对照课件。自己改写的练习放入对应技术目录。
7. 相同题目的不同学习版本分别保留，通过目录标明阶段；不要用覆盖来消除同名文件。
8. 示例数据与脚本放在同一章节；新代码优先用 `Path(__file__).parent` 定位素材。`.env`、虚拟环境、缓存不提交 Git。
9. 每个新章节补充 README：学习目标、阅读顺序、运行方式、所需服务，以及个人复盘。
