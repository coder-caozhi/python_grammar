# Git 学习历史阅读指南

既有提交历史完整保留。此次整理按知识点分批提交，每条提交使用实际提交时间；分组代表学习主题和整理步骤，不代表这些内容恰好在提交当天学完。

原 PythonProject 只有暂存内容、没有正式提交，无法恢复不存在的提交时间线；现有代码按下列主题纳入当前仓库。

1. 清理版本管理：忽略环境、私有配置、IDE 设置及缓存。
2. Python 基础：语法、容器、函数、面向对象、文件与异常的目录整理。
3. Python 实践：调试、学生管理、记账与电商综合练习。
4. 课程参考：保持课件内部命名，集中放入课程资料区。
5. FastAPI：部门员工 CRUD。
6. FastAPI：路由、参数与 ORM 练习；数据库配置从本地 .env 读取。
7. LangChain 入门：环境、模型、Ollama、提示词及调用方式。
8. LangChain 编排：输出解析、LCEL、记忆与工具。
9. LangChain 应用：向量、RAG、MCP 与 Agent。
10. 学习导航：命名规则、迁移对照、LangGraph 学习区。

查看：`git log --oneline --graph`。查看具体文件沿重命名之前的历史：`git log --follow -- 文件路径`。
