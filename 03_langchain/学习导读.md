# LangChain 代码学习导读

每个 Python 文件开头都有学习目的、技术讲解、阅读路线、实际行为提示和动手验证；关键语句旁有 `【理解这一行】` 注释。原有代码和文档字符串保持不变，避免改变工具描述或运行行为。

## 阅读顺序

先读模型输入输出与提示词，再读解析器和 LCEL；掌握数据流后学习历史、工具、向量、RAG，最后比较 MCP 和 Agent。不要仅凭文件名判断供应商或接口版本。

## 已核对的易错点

- 具体 SystemMessage/HumanMessage 内容中的花括号不自动成为模板变量。
- TypedDict/Annotated 本身不会自动校验运行时的字段值。
- JsonOutputParser 指定 schema 不等于 PydanticOutputParser 的运行时模型校验。
- bind_tools 只让模型知道工具；必须再有执行工具并回填结果的流程。
- MCP 本地模拟与真正 SDK 服务不同；A2A 模拟报告也不代表真实平台交易。
- 本目录有历史版本示例和待完善代码，注释会指出具体限制，不将其描述成已验证的完整实现。

## 核验与参考

本次为教学注释增强：84 个文件的 AST 与非注释 token 均逐项对比，保持执行语句、参数和原有 docstring 不变。未批量执行模型请求、Redis 写入、天气查询、交互循环或服务器。

部分易错行为已用本机安装版本离线验证；模型服务能力与版本兼容仍需按运行环境核对。

- [LangChain 聊天模板源码](https://github.com/langchain-ai/langchain/blob/master/libs/core/langchain_core/prompts/chat.py)：消息实例、模板与可选占位符的区别。
- [LangChain Agent 文档](https://docs.langchain.com/oss/python/langchain/agents)：Agent 工具循环和消息状态输入。
- [MCP Python SDK](https://github.com/modelcontextprotocol/python-sdk)：真实协议 SDK，与本地注册表示例区分。
