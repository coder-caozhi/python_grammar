> 难度：★☆☆☆☆（和「猜数字」差不多）

> 说明：本练习**只用到基本语法**，不需要函数 / 类 / 模块，纯 if / 循环 / 列表就能搞定。

## 一、需求描述

写一个命令行小程序，模拟在超市买东西后的「结算」过程：

1. **打印欢迎语**
   - 用 `print` 打印一条分隔线（例如 30 个 `=`，可以用 `"=" * 30`）。
   - 打印一句欢迎语，例如「欢迎使用超市结算小助手」。

2. **循环录入商品**
   程序反复询问用户：
   ```
   请输入商品名称（输入 q 结算）：
   请输入商品价格：
   ```
   - 用户每输入一个商品，就把这个商品的**名称**和**价格**存起来。
   - 当用户在「商品名称」处输入 `q` 或 `Q` 时，结束录入（用 `break` 跳出循环）。
   - 如果用户输入的价格**不是数字**（比如输入了 `abc`），要提示「价格输入有误，请重新输入」，然后**跳过这一次**，重新问（用 `continue`）。

3. **打印购物清单**
   录入结束后，遍历所有商品，逐行打印：
   ```
   1. 苹果    5.5 元
   2. 牛奶    12.0 元
   ```
   最后打印一行「共 N 件商品」。

4. **计算总价**
   - 把所有商品价格加起来，得到**原价**。
   - 打印原价，例如 `原价：XX 元`。

5. **根据金额打折**（用 `if / elif / else`）
   - 原价满 **200 元及以上**：打 **8 折**（× 0.8）。
   - 原价满 **100 元（含）到 200 元之间**：打 **9 折**（× 0.9）。
   - 不满 100 元：**不打折**。
   - 打印用了哪种折扣（例如「已享受 9 折优惠」）。

6. **打印最终金额**
   - 打印「应付金额：XX 元」。
   - 最后打印「感谢光临，欢迎下次再来！」。

## 二、需要用到的语法点（对照检查）

做完后可以对照下面清单，看看哪些用上了：

| 语法点 | 在哪里用到 |
| --- | --- |
| 变量与赋值 | 商品名、价格、总价、折扣等 |
| 字符串 / f-string | 输出提示语，`f"应付金额：{total} 元"` |
| `print` 输出 | 全程打印提示和结果 |
| `input` 输入 | 读取商品名和价格 |
| 类型转换 | `float(input(...))` 把输入的字符串转成小数 |
| 运算符 | `+`、`*`、`>=`、`>` 等 |
| `if / elif / else` | 判断打折档位 |
| `while` 循环 | 反复录入商品 |
| `break` | 输入 `q` 结束录入 |
| `continue` | 价格非法时跳过本次 |
| 列表 | 存放所有商品 |
| `list.append()` | 每录入一个商品就追加 |
| `for` 遍历 | 打印购物清单 |
| `sum()` | 计算总价 |
| `f-string` 格式化 | 让金额保留 2 位小数，如 `{total:.2f}` |

> 小提示：商品可以用一个小列表存起来，比如 `items = []`，
> 然后每个商品存成 `[名称, 价格]`，再 `items.append([name, price])`。
> 打印时用 `items[i][0]` 取名称、`items[i][1]` 取价格。
